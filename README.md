# ГОЛОГРАММА

Сайт-голограмма с системой страниц и двумя режимами доступа.

## Пароли

- **Зритель:** `взб` — только чтение опубликованных страниц
- **Админ:** `4goosE` — создание, редактирование, удаление страниц

## Как работает

1. Открой `index.html` (на GitHub Pages или локально)
2. Войди под паролем админа
3. Создавай, редактируй, удаляй страницы (черновики хранятся в localStorage браузера)
4. Нажми **СКОПИРОВАТЬ КОД** — получишь полный автономный HTML
5. Вставь код в новый файл, сохрани — это опубликует страницы

## Структура

- `index.html` — разметка страницы
- `style.css` — стили голограммы
- `script.js` — логика редактора
- `.nojekyll` — отключает Jekyll на GitHub Pages

## Запуск на GitHub Pages

1. Загрузи все файлы в репозиторий
2. Settings → Pages → Branch: main → Save
3. Сайт будет доступен по адресу `https://твой-ник.github.io/название-репозитория/`
